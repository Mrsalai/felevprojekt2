Téma:
A Recipe Finder egy angol nyelvű, reszponzív receptböngésző weboldal (az angol nyelvű DummyJSON API-hoz igazítva), ahol a látogatók receptek között kereshetnek, rendezhetik őket és véletlenszerű főzési ötletet kérhetnek. Az oldalon emellett összefoglaló adattáblázat és új recept beküldésére szolgáló űrlap is található.

Technológiák:
HTML5, CSS3 (mobile-first Flexbox, CSS változók, Google Fonts), vanilla JavaScript (fetch API, async/await, DOM-kezelés).

Használt nyilvános, kulcs nélküli REST API és adatleképezés:
- DummyJSON Recipes API:
  - GET  https://dummyjson.com/recipes?limit=0 (összes recept betöltése a kereső- és a táblázatoldalon)
  - GET  https://dummyjson.com/recipes/{id} (egy véletlenszerű recept lekérése 1–50 közötti ID-val)
  - POST https://dummyjson.com/recipes/add (új recept beküldése JSON-törzzsel, a válasz tartalmazza a kapott ID-t)
- Adatleképezés a témára:
  - name -> recept címe (kártya h3 / táblázat th scope="row")
  - image -> recept képe (img, alt = name)
  - cuisine, difficulty, caloriesPerServing -> konyhatípus, nehézség, kalória / adag
  - prepTimeMinutes + cookTimeMinutes -> teljes elkészítési idő percben (megjelenítéshez és rendezéshez)
  - ingredients, instructions -> hozzávalók (ul) és elkészítési lépések (ol) a Random recept oldalon

Oldalak és fájlstruktúra:
- index.html          : Kezdőlap bemutatkozással, főzési tippel (aside) és 3 kiemelt receptkártyával.
- kereses.html        : Élő receptkereső és rendező oldal.
- receptek.html       : Áttekintő adattáblázat (caption, thead, tbody, th scope, zebracsík, görgethető konténer).
- random-recept.html  : Véletlen recept ajánló oldal gombnyomásra frissülő recepttel.
- uj-recept.html      : Új recept beküldő űrlap 5 mezővel (text, select, number, radio) és POST kéréssel.
- css/stilus.css      : Egyetlen közös, mobile-first külső stíluslap (40em és 60em töréspontokkal).
- img/                : Helyi receptfotók a kezdőlaphoz (teszta.jpg, leves.jpg, piritos.jpg).

JavaScript-fájlok:
- js/kereses.js       : GET fetch (limit=0), render(lista), élő keresés (filter), rendezés (sort) az eredeti tömb megőrzésével, darabszám és hibaállapot.
- js/receptek.js      : GET fetch (limit=0), összes recept megjelenítése táblázatsorokként (tr, th scope="row", td).
- js/random-recept.js : Véletlen ID (1–50), GET fetch (/recipes/{id}), receptkártya hozzávalókkal és elkészítési lépésekkel, újrasorsolás gomb.
- js/uj-recept.js     : Űrlap submit kezelése preventDefault()-tal, adatok kiolvasása objektumba, POST fetch JSON-törzzsel, kapott ID és hibaág megjelenítése.
